# Stroke Prediction System

## Overview

The Stroke Prediction System is a machine learning-based web application developed using Flask that predicts the likelihood of stroke risk based on various health-related parameters. The application provides a secure authentication system and an intuitive interface for users to input medical information and receive prediction results.

## Features

* User Registration and Login
* Secure Session Management
* Machine Learning-Based Stroke Prediction
* Interactive and Responsive User Interface
* Dashboard for Authenticated Users
* Real-Time Prediction Results
* Input Validation
* CSV-Based User Data Storage
* Flask Backend Integration

## Project Workflow

1. User registers or logs into the system.
2. User enters health-related information.
3. The Flask application processes the input data.
4. The trained machine learning model analyzes the data.
5. The system predicts the stroke risk level.
6. The result is displayed on the screen.

## Input Parameters

The model uses the following attributes for prediction:

* Gender
* Age
* Hypertension
* Heart Disease
* Ever Married
* Work Type
* Residence Type
* Average Glucose Level
* BMI
* Smoking Status

## Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/stroke-prediction-system.git
cd stroke-prediction-system
```

### Step 2: Create a Virtual Environment

```bash
python -m venv venv
```

### Step 3: Activate the Environment

For Windows:

```bash
venv\Scripts\activate
```

For Linux/Mac:

```bash
source venv/bin/activate
```

### Step 4: Install Required Packages

```bash
pip install -r requirements.txt
```

### Step 5: Run the Application

```bash
python app.py
```

### Step 6: Open the Application

Visit:

```text
http://127.0.0.1:5000
```

## Dataset

The project is trained using a healthcare stroke dataset containing demographic and medical information of patients. The dataset is used for training and evaluating the machine learning model.

## Machine Learning Model

The prediction model is trained using healthcare data and saved as a serialized model file. The model evaluates user inputs and classifies the stroke risk accordingly.
